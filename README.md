# On Large-Scale Multiple Testing Over Networks: A Non-Asymptotic Approach

Code, results, and manuscript for the paper

> M. Pournaderi, *On Large-Scale Multiple Testing Over Networks: A
> Non-Asymptotic Approach*, 2026.

The paper develops **finite-sample false discovery rate (FDR) control** for
distributed multiple testing under communication constraints, building on the
greedy interval-aggregation algorithm of Pournaderi & Xiang (IEEE TSIPN,
2024), whose FDR guarantee is asymptotic only. Contributions:

- a tight characterization of the finite-sample failure: a winner's-curse
  selection bias of exact order Θ(m^{-1/4} √log m) at the standard bandwidth
  (upper bound in general, matching lower bound under the global null);
- **CFGA** (cross-fit greedy aggregation) and an **inflated** plug-in variant
  with finite-sample guarantees;
- **e-CFGA**: derandomized e-value aggregation over random splits that
  removes the cross-fitting Bonferroni factor;
- **BONuS-GA**: a split-free masking procedure with a fully implementable
  **per-node budgeted** tier (no oracle input, valid even for fixed
  adversarial node assignments);
- a data-driven bandwidth selection rule that preserves every guarantee.

All procedures keep the original algorithm's O(√m log m) total communication
budget.

## Repository layout

```
paper/      IEEE-format manuscript (main version) + figures + PDF
paper/jmlr/ JMLR-format version (single column) + PDF
code/       simulation library and experiment drivers (Python 3, NumPy/SciPy/Matplotlib)
results/    assembled per-experiment results (.npz), one file per sweep axis
```

## Code map

| File | Role |
|---|---|
| `simulations.py` | method library: baselines, greedy, CFGA (+Storey/adaptive ε), Inflated CFGA, BONuS-GA |
| `ecfga.py` | e-CFGA (Storey and inflated tiers, derandomized over S splits) |
| `bonus_pernode.py` | per-node calibrated and per-node **budgeted** BONuS-GA |
| `sweep_quiet_nodes.py` | Experiment 1 (Local-BH failure as quiet nodes accumulate) |
| `mn_sweep.py` | Experiments 2–6 (signal strength, dependence, hub size, Cauchy, target α) |
| `bonus_sweep.py` | BONuS-GA curves at the same sweep points/seeds |
| `prov_sweep.py` | provable-tier curves (inflated e-CFGA, budgeted BONuS-GA) |
| `bonus_mechanism_test.py` | Table I ablation at m_hub = 250 |
| `replot.py` | redraws all six figures from the `.npz` files (no recomputation) |

## Reproducing the experiments

```bash
pip install -r requirements.txt
cd code

# Experiments (chunked; each point is saved and runs resume):
python sweep_quiet_nodes.py all          # Experiment 1
python mn_sweep.py mu                    # Experiments 2-6: mu, rho, alpha, n, cauchy
python mn_sweep.py plot mu               # assemble sim_mn_mu.{png,npz}
python bonus_sweep.py all                # BONuS-GA overlay (same seeds)
python prov_sweep.py quiet ecfga_inf     # provable tiers, per axis/method
python prov_sweep.py assemble
python bonus_mechanism_test.py           # ablation table
python replot.py                         # final figures from the .npz files
```

Outputs are written to `code/outputs/`. The `results/` directory contains the
assembled `.npz` files used for the figures in the paper (arrays `x`,
`fdr_<method>`, `pwr_<method>` per sweep axis), so the figures can be
restyled or re-analyzed without rerunning anything:

```python
import numpy as np
d = np.load("results/sim_mn_n.npz")
print(d["x"], d["fdr_CFGA + Storey + adaptive eps"])
```

To reuse the stored results with `replot.py`, copy `results/*.npz` into
`code/outputs/` first. Per-point resume caches (`_mn_*`, `_qn_*`, `_prov_*`)
are not tracked; they are regenerated by the sweep drivers.

## Building the paper

```bash
cd paper && pdflatex finite_sample_fdr_greedy.tex              # IEEE version (embedded bibliography)

cd paper/jmlr                                                  # JMLR version (natbib + BibTeX)
pdflatex finite_sample_fdr_greedy_jmlr.tex
bibtex   finite_sample_fdr_greedy_jmlr
pdflatex finite_sample_fdr_greedy_jmlr.tex
pdflatex finite_sample_fdr_greedy_jmlr.tex
```

(Figure files are expected next to each `.tex`; copy them from
`paper/figures/` if needed.)

## Requirements

Python ≥ 3.9 with `numpy`, `scipy`, `matplotlib` (see `requirements.txt`).
No GPU or special hardware; every experiment runs on a laptop CPU.
